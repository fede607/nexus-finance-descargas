# NEXUS FINANCE — descargas

Finanzas personales privadas. Cada persona crea su propia cuenta con su contraseña y sus datos se cifran (Argon2id + XChaCha20-Poly1305) y se quedan **solo en su dispositivo**. No hay servidor, registro ni base de datos central.

## Empezar

- **Desde el navegador (cualquier dispositivo, también iPhone y iPad):** https://fede607.github.io/nexus-finance-descargas/ — añádela a la pantalla de inicio para que el navegador no borre los datos.
- **App instalada:** https://fede607.github.io/nexus-finance-descargas/descargas/ (Android, Windows, Mac, Linux/Chromebook).

## Importante

- **No hay recuperación de contraseña.** Si la olvidas, nadie puede abrir tus datos.
- **No se sincroniza** entre dispositivos: pasa tus datos con una copia cifrada (Ajustes → Copias de seguridad).
- Comprueba los instaladores con [`archivos/SHA256SUMS.txt`](archivos/SHA256SUMS.txt).

Este repositorio solo contiene la app compilada y los instaladores; el código fuente es privado.
